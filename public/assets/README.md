# Generated game artwork

These are newly generated cartoon approximations, created with the built-in imagegen tool. They are not extracted original game files.

- plants.png: 49 plant designs with transparent backgrounds.
- zombies.png: 26 zombie designs plus lawn/pool/roof cleaners and Stinky.
- environments.png: Day, Night, Pool, Fog, Roof, and main menu.
- interface.png: pickups, projectiles, shovel, frames, buttons, and trophy.
- manifest.json: actual per-subject crop rectangles; layouts are not uniformly spaced.
- generation-prompts.json: the prompts used for this pack.

The renderer crops sprites at load time and animates mesh vertices and transforms. These sheets contain base poses, not hand-drawn animation sequences. Environment tiles are scenery, not collision grids. Generated art differs from the original screenshot and is not pixel-perfect.
